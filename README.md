# Calorie Avatar 🥗

**Calorie Avatar** is an AI-driven virtual nutrition coach designed to help users track their calorie intake and make personalized food choices. It uses AI-based food recognition and personalized recommendations to support healthy weight-management goals through an interactive 2D avatar.

### Features

* 🍎 AI-based food recognition using YOLOv8
* 🔥 Personalized calorie and nutrition recommendations
* 🥗 Healthier food-swap suggestions
* 👤 Interactive 2D virtual avatar
* 📊 Personalized calorie tracking

### Tech Stack

**React • Node.js • Python • FastAPI • YOLOv8 • HTML/CSS**
